# Overview

This software analyzes a free dataset of international soccer match results using Python and Pandas.

The purpose of this software is to practice organizing, filtering, sorting, and aggregating real world data. The program answers two questions:

1. Which teams have scored the most goals in the dataset?
2. Which teams have the highest average goals per match among teams with at least 100 matches?

The program also creates a bar graph showing the teams with the most total goals as a stretch challenge.

The dataset contains international men's soccer match results, including the teams, scores, dates, tournaments, and locations.
